# Golems Kill Creepers

A tiny mod that adds two gamerules to allow Iron Golems to attack and instakill Creepers.

- `doIronGolemsAttackCreepers`
  - Controls whether Iron Golems actively target Creepers
  - Default: `true`
- `doIronGolemsInstakillCreepers`
  - Controls whether Iron Golems deal maximum damage to Creepers when attacking
  - Default: `true`
